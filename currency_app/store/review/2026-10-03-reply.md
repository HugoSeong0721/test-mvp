The app has no account registration, no login, no user-generated content, and no paid content or in-app purchases.

2. Purpose and target audience
Glance FX is a currency converter for travelers, people shopping from overseas online stores, people sending money abroad, and freelancers paid in foreign currencies.
Problem it solves: most converters show one currency pair at a time. Glance pins the user's home currency at the top and shows any number of other currencies below it. Typing in any row updates every other row instantly, so the user can compare many currencies at a glance. It also shows the daily change of each rate, real historical rate charts, and keeps working offline with the last saved rates.

3. How to use the main features (no login, credentials, or sample files needed)
- On first launch, choose a base currency (for example USD).
- Convert tab: tap any amount to type with the built-in keypad; every other row updates. Tap a currency code to replace or remove it. Tap "Add currency" to add more (search "gold" or "bitcoin"). Long-press a row and drag to reorder.
- Chart tab: tap either currency chip to change the pair, tap the swap button to reverse it, and choose 1W, 1M, 3M or 1Y.

4. External services
- Exchange rate data: the free, public Currency API by fawazahmed0 (https://github.com/fawazahmed0/exchange-api, CC0 license), loaded over HTTPS from cdn.jsdelivr.net with currency-api.pages.dev as a mirror. Requests are read-only and contain no user data. No API key is used.
- Advertising: Google AdMob (Google Mobile Ads SDK) shows one banner ad.
- The app uses no authentication, payment, analytics, or AI services, and has no backend server of its own.

5. Regional differences
The app works the same in all regions. All content is in English and the exchange rates are global.

6. Regulated industry / third-party material
The app only displays informational exchange rates and converts amounts. It does not provide trading, money transfers, payments, banking, or financial advice, so no financial license applies. The rate data is public domain (CC0).
