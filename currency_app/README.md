# 환율 앱 (Currency Converter) — 벤치마크 & UI 프로토타입

경쟁사 **My Currency Converter & Rates** (JRustonApps B.V., ★4.9 / 128K 리뷰)를 분석해서
유지할 것 / 추가할 것 / 뺄 것을 정리하고, 세련된 UI로 재해석한 인터랙티브 프로토타입입니다.

- 프로토타입: [`currency-app-preview.html`](./currency-app-preview.html) — 브라우저에서 바로 열면 동작합니다 (모바일 화면 기준).

---

## 1. 경쟁사 분석

### 잘하는 것 (그대로 유지)
| 항목 | 내용 |
|---|---|
| 입력 즉시 변환 | "Convert" 버튼 없이 타이핑과 동시에 변환 |
| 전용 키패드 | 시스템 키보드 대신 큰 커스텀 키패드 |
| 통화 커버리지 | 법정통화 150+ / 암호화폐(BTC 등) / 귀금속(XAU, XAG, XPD, XPT) |
| 즐겨찾기 | 한 금액을 여러 통화로 한 번에 보는 리스트 |
| 차트 | 1D / 7D / 1M / 1Y 기간별 환율 차트 |
| 오프라인 | 마지막 환율 캐시로 오프라인에서도 동작 (여행자에게 핵심) |
| 통화 검색 | 추천(Suggestions) + 전체 목록 + 검색 |

### 아쉬운 것 (개선 포인트)
| 문제 | 스크린샷 근거 | 우리 해법 |
|---|---|---|
| 소수점 처리 버그 수준 | 즐겨찾기에서 `120 USD → 0.00 BTC` | **스마트 정밀도**: 1 미만 값은 유효숫자 기준 표시 (`0.00134 BTC`) |
| 변동 정보 없음 | 환율이 올랐는지 내렸는지 알 수 없음 | 전일 대비 **▲▼ % 표시** (변환/차트/즐겨찾기 전부) |
| 낡은 UI | 순백 배경, 원색 빨강 삭제키, 밋밋한 타이포 | 다크 퍼스트 + 골드 악센트, 큰 라이트웨이트 숫자, 라이트 테마 자동 |
| 광고 | "This version is ad-supported" | **광고 제거** (수익화는 추후 프리미엄 기능으로) |
| 과도한 트래킹 | App Privacy: 위치·식별자·사용 데이터로 **크로스앱 추적** | 추적 없음 — 환율 API 호출 외 데이터 수집 안 함 |
| 환율 신선도 불명 | 언제 환율인지 표시 없음 | 헤더에 **기준 시각 + 오프라인 배지** 상시 표시 |

### 추가하는 것 (경쟁사에 없음)
1. **전일 대비 변동률** — 모든 화면에서 ▲▼ %
2. **양방향 입력** — 받는 쪽 금액을 탭하면 역방향으로 바로 입력 가능
3. **스마트 정밀도** — 통화별 소수점 자동 조절 (JPY 0자리, BTC 8자리, 금액 크기 반영)
4. **환율 알림** (스텁) — 목표 환율 도달 시 푸시
5. **다크/라이트 테마** — 시스템 설정 자동 추종
6. **최근 사용 통화** — 검색 시트 상단에 노출

### 빼는 것
- 광고 배너
- 크로스앱 추적 (위치/식별자)
- 3자리 고정 소수점 ("3 decimal places" 자랑거리가 아니라 한계였음)

## 2. 프로토타입 범위

| 화면 | 구현 내용 |
|---|---|
| 변환 | 맨 위에 기준 통화·금액(내 돈, 통화 변경 가능. 숫자판은 첫 화면에 없고 금액을 눌러야 올라옴) → 아래 여러 국가가 동시에 변환. 반투명 글라스 ＋ 버튼으로 국가 추가, 행을 눌러 통화 교체·제거. 각 행에 단위 환율·전일 대비 ▲▼ 표시 |
| 차트 | 기간 선택(1일~1년), SVG 영역 차트, 고가/저가, 알림 스텁 |

- 환율은 **내장 예시 데이터** (스냅샷 기준 표기). 실제 앱에서는 무료 환율 API(예: frankfurter.dev, open.er-api.com)로 교체.
- 기준 통화·금액/대상 국가 목록/최근 통화는 `localStorage`에 저장.
