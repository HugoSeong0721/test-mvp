Cozy Coloring 정식판 기획서

조사: 작업자 5명이 병렬로 진행(미국 상위 앱 · 어르신·출퇴근 사용자 · CC0 선화 출처 · 라이선스 반박 검증 · 칸 변환기)

한 줄 요약
버스 한 정거장(3~5분)이면 그림 하나를 끝내는, 글자 크고 광고가 방해하지 않는 숫자 색칠 앱. 그림은 저작권 없는(CC0) 전문 선화를 사람이 한 장씩 골라 가져오고, 변환기로 칸과 번호를 자동으로 만든다.

2. 누구를 위한 앱인가 (숫자로 정한 규칙)

  • 버튼 최소 60pt, 목표 80pt(약 14mm). 65세 이상은 14mm보다 작으면 정확도가 확 떨어진다는 연구 결과가 있다. 애플 최소 기준은 44pt.
  • 글자: 본문 20pt 이상, 팔레트 숫자 24~28pt 굵게, 그림 위 숫자는 16pt 아래로 줄이지 않음(작아지면 확대해야 보이게).
  • 색약 배려: 모든 색 칸에 숫자 표시, 빨강·초록이 비슷한 밝기로 붙어 있지 않게.
  • 설명 화면 없음: 첫 그림이 바로 열리고, 첫 색이 이미 골라져서 깜빡임 → 첫 탭이 곧 튜토리얼.
  • 화면은 2단계뿐: 홈(갤러리) ↔ 색칠. 왼쪽 위 큰 "Back" 글자 버튼.
  • 탭만 사용: 길게 누르기·스와이프 전용 기능 없음. 확대는 핀치 + 큰 ＋/－ 버튼.
  • 완전 오프라인: 지하철 터널은 대부분 끊긴다. 그림은 앱에 넣어 두고 오늘의 그림은 전날 미리 받음. 65세 이상 17%는 집에 인터넷이 없다(Pew).
  • 매 탭마다 자동 저장: 2분 칠하다 내려도 잃는 게 없음.
한 판 길이: 모바일 게임 평균 세션이 3.1~3.5분(GameAnalytics) → 그림 1장 = 1세션. 미국 대중교통 통근 평균은 약 45~50분이라 오늘의 그림 1장 + 추가 2~3장을 준비한다.

4. 그림 품질 — CC0 선화 가져오기

저작권 없는 그림이라고 적혀 있어도, 상업 앱에 넣어도 되는지는 다른 문제다. 그래서 출처마다 "쓰면 안 되는 이유"를 일부러 찾는 반박 검증을 한 번 더 돌렸다.

출처판정왜
Openclipart (SVG 약 18만 장, "coloring book" 태그 약 330장)주력전부 CC0, 앱 안 사용 명시 허용. 단 한 장씩 골라야 함: AI 생성·캐릭터·로고 제외
Wikimedia Commons (PD-old-100 · CC0만)조건부파일마다 라이선스가 다름. CC BY-SA나 "미국만 PD"는 제외
Smithsonian · The Met · Rijksmuseum · NYPL조건부CC0 표시된 것만 쓰면 가장 안전. 대신 판화라 빗금 정리 작업이 많음 → 장식 문양·고급 그림용
FreeSVG · Public Domain Vectors · rawpixel쓰지 않음다른 데서 퍼온 그림이 섞여 있음(삭제된 사례 있음), 이용약관 확인 불가. 원본이 Openclipart에 있으면 거기서 가져온다
Biodiversity Heritage Library · Internet Archive 옛 책제외"비상업 이용만" 문구가 있음 / 날짜 정보가 틀린 경우가 많음
그림마다 남길 기록: 출처 페이지 주소, 작가, 라이선스, 라이선스 화면 캡처(웨이백 주소), 받은 날짜, 원본 파일 지문(SHA-256), 어떻게 고쳤는지, 캐릭터·로고 검사 결과, 검수자, 승인/반려와 이유.
목표: 첫 출시 30~50장(오늘의 그림 30일치 + 주제 선반 3~4개).

5. 칸 자동 변환기 (선화 → 칸 + 번호)

  1. 정리: 흑백으로 바꾸고 누런 종이 얼룩 제거
  2. 끊긴 선 잇기: 선이 끊겨 있으면 색이 옆 칸으로 새므로 칸 계산할 때만 이어 줌(보이는 선은 원본 그대로)
  3. 칸 나누기: 선으로 둘러싸인 영역마다 칸 하나
  4. 작은 칸 없애기: 손가락으로 못 누르는 칸은 옆 칸에 합치거나 미리 칠해 둠. "마지막 칸을 못 찾음" 불만을 원천 차단
  5. 색 정하기: 자동 색은 탁해 보임(지난번 '싸 보임'의 원인). 그림마다 사람이 고른 팔레트에 맞춤, 8~16색, 비슷한 색은 합침
  6. 번호 위치: 칸 안에서 가장 넓은 지점(polylabel). 웹 원형에서 숫자가 칸 밖으로 나가던 문제를 해결
  7. 품질 검사: 칸 수 범위, 최소 크기, 모든 칸이 실제로 탭되는지 테스트 로봇이 확인 → 통과한 그림만 앱에 넣음
변환은 미리 컴퓨터에서 해 두고, 앱에는 결과 파일(그림당 수십 KB 예상, 미측정)만 넣는다. GPL 라이선스 도구(potrace)는 앱에 넣지 않는다.

6. 돈 버는 방식 10/2 결정 반영

처음부터 돈 내라고 하지 않는다. 결제 없이 광고만으로 운영.
  • "영상 보고 계속 칠하기": 그림을 몇 장 다 칠하면, 다음 그림을 시작하기 전에 "▶ Watch a short video to keep coloring" 큰 버튼 화면이 나온다. 보상형 광고라 전면 광고보다 단가가 높고, 사용자가 직접 누르는 방식이라 애드몹 정책에도 맞다
  • 칠하는 도중에는 절대 안 뜬다: 그림 완성 → 축하 → 그다음에만 (리뷰 1위 불만 차단)
  • 오늘의 그림은 광고 없이 무료: 매일 들어올 이유는 막지 않는다
  • 광고를 못 불러오면 그냥 계속: 지하철 터널(오프라인)에서 막히는 일 없음
  • 배너: 홈 화면에만 (색칠 화면엔 없음)
  • 힌트: 그림마다 1번 무료, 더 필요하면 영상 보고 받기
  • 결제(광고 제거)는 v1에 넣지 않는다: 손이 덜 가고(구매 복원·환불 대응 없음) 성공 기준(월 광고 수익)에 바로 맞음. 나중에 "광고 싫다" 리뷰가 많으면 그때 추가

7. 앱 이름·검색어 10/2 결정 반영

미국 상위 앱 제목에 가장 많이 들어간 말: color by number > paint by number > coloring book/games.
"for Seniors" 같은 말은 쓰지 않는다(나이 든 사람용이라고 광고하지 않음). 큰 글씨는 화면으로 보여 주고, 글로는 말하지 않는다.
이름 후보: Cozy Color: Color by Number · 부제 후보: Relaxing Paint by Number 또는 Easy Paint by Number
⚠ 애플 검색 인기도 점수는 얻지 못했다(경쟁 앱 제목으로 추정). 이름 중복 여부도 아직 확인 못 했다 → 앱스토어 등록 단계에서 확인.

8. 결정해 주실 것 (2개 남음)

B. 몇 장마다 "영상 보고 계속하기"?

1
2장마다: 출퇴근 한 번(약 45분, 5~10장)에 광고 2~5번. 수익 우선
2
3장마다: 출퇴근 한 번에 광고 1~3번. 덜 귀찮음

추천: 2번(3장마다)으로 시작. 광고가 덜 귀찮아야 오래 남고, 출시 후 수익·이탈을 보고 2장으로 조일 수 있다

D. 그림 한 장의 칸 수

1
60~100칸(오늘의 그림), 큰 그림은 최대 150칸: 어르신 속도 기준, 3~5분에 끝남
2
100~200칸: 경쟁 앱 수준으로 더 화려하지만 5분이 넘을 수 있음

추천: 1번. 두 조사 결과가 서로 달랐고(40~80 vs 100~200) 둘 다 추정치다. TestFlight에서 실제 걸린 시간을 재서 조정한다

결정 기록 (10/2): A → "for Seniors" 안 씀 · 전면 광고/광고 제거 결제 → 결제 없이 "영상 보고 계속하기"로 대체

9. 확인 못 한 것

  • 이 작업 환경에서는 앱스토어·Openclipart·박물관 사이트가 네트워크에서 막혀 있어, 평점·가격·라이선스 문구는 검색 결과 요약으로만 확인했다(원문 페이지를 직접 열지 못함). 숫자는 지역·시점이 섞였을 수 있다.
  • 같은 이유로 그림 파일을 여기서 직접 내려받을 수 없다 → GitHub Actions에서 받거나, 네트워크 허용 목록에 사이트를 추가해야 한다. 개발 단계 첫 번째 과제.
  • FreeSVG·Public Domain Vectors 이용약관 원문은 읽지 못함 → 그래서 쓰지 않기로 함.
  • 칸 수·탭 시간·파일 크기는 추정치. 실제 아이폰에서 칸 200개 렌더링 속도는 측정하지 않았다.
  • Vita Color가 "Color Aura"로 이름을 바꿨다는 정보는 스토어에서 확인하지 못했다.
