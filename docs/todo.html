테스트해 보려면 ①만 하면 돼요. 앱마다 한 번 등록하면, 그 뒤엔 세션이 빌드를 올리고 TestFlight 초대 메일이 와요 → 메일의 코드를 TestFlight 앱에 입력. ②AdMob 은 스토어 제출 직전에.

① App Store Connect — 신규 앱 (앱마다 1~2분)

appstoreconnect.apple.com → 앱 → ＋ → 신규 앱. 플랫폼 iOS, 기본 언어 English (U.S.), 사용자 액세스 Full Access. 이름·번들·SKU 만 아래 값으로.

② (나중에, 스토어 제출 전) AdMob — 앱 + 배너 광고 단위

admob.google.com (soulfulfillable 계정) → 앱 → 앱 추가 → iOS → "스토어에 등록되지 않음" → 이름 입력 → 광고 단위 추가 → 형식은 "배너(Banner)" 카드, 이름은 banner 직접 입력.
다 만든 뒤 AdMob 앱 목록·광고 단위 화면을 캡처해서 각 세션에 붙여 넣으면 세션이 ID를 읽어 넣어요.
급하지 않아요 — TestFlight 까지는 테스트 광고로 돌고, 스토어 제출 전에만 있으면 돼요.

체크 표시는 이 폰에만 저장돼요. 새 앱이 생기면 기획 파트너가 이 페이지에 추가합니다.
