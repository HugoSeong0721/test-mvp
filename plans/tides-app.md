# 물때 시간 (Tides) — 기획서 (기획 파트너, 2026-10-02)

## 왜
- "tides near me" 미국 월 약 1.5만 검색 (Ahrefs). 1등 Tides Near Me 4.8★ 약 16.2만 평가 (`plans/utility-research.md`).
- 1등의 불만: **물때 한 번 보려는데 30초 광고**, 광고 제거 단건 결제 없음.
- 데이터: **NOAA CO-OPS API** (미국 정부, 무료, 키 없음, 관측소 약 3,500곳 — 개수는 NOAA 페이지에서 재확인). 서버 불필요.
- 낚시·해변·카약·보트 전에 "가끔" 확인하는 앱. 미국 해안 한정.

## 핵심 화면 (한 화면에서 끝나게)
- 위치 권한 → **가장 가까운 관측소** 자동 선택 (권한 거부 시 도시/관측소 검색).
- **오늘 물때 곡선** 크게 + 지금 위치 표시, 다음 만조·간조 시각과 높이, "Rising/Falling" 화살표.
- 7일 표. 일출·일몰·달 모양(계산식으로 오프라인 산출).
- 즐겨찾기 관측소 몇 개. 마지막 데이터 캐시 → 바다 근처 신호 약할 때도 보이게("Last updated" 표시).

## 원칙
- 숫자는 NOAA 실제 예보값만. 데이터 못 받으면 솔직히 "No data" + 캐시 시각 표시. 가짜 곡선 금지.
- "Not for navigation" 표기 (항해용 아님).
- 광고: **배너만, 전면 광고 없음**(1등 앱 불만의 정반대가 우리 무기). 보상형은 부가 기능(예: 30일 표)에만 검토.
- 영어 UI, 피트(ft) 기본·미터 전환, 아이폰 전용·세로.

## 결정 필요 (개발 세션이 사용자에게 A/B 로)
- 앱 이름: 미국 검색어 조사 후 후보 2~3개.
- 번들 ID `com.soulfulfill.<이름>` — Apple 등록 전 확인.
- 광고 제거 단건 결제(예: $2.99)를 넣을지 — 1등 앱 리뷰 불만이 "단건 결제 없음"이었다. 지금까지 방침은 결제 없이 광고만.
