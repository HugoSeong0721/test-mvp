# 물때 시간 (Tides) — 기획서 (기획 파트너, 2026-10-02)

## 왜
- "tides near me" 미국 월 약 1.5만 검색 (Ahrefs). 1등 Tides Near Me 4.8★ 약 16.2만 평가 (`plans/utility-research.md`).
- 1등의 불만: **물때 한 번 보려는데 30초 광고**, 광고 제거 단건 결제 없음.
- 데이터: **NOAA CO-OPS API** (미국 정부, 무료, 키 없음, 관측소 약 3,500곳 — 개수는 NOAA 페이지에서 재확인). 서버 불필요.
- 낚시·해변·카약·보트 전에 "가끔" 확인하는 앱. 미국 해안 한정.

## 핵심 화면 (한 화면에서 끝나게)
- 위치 권한 → **가장 가까운 관측소** 자동 선택 (권한 거부 시 도시/관측소 검색).
- **오늘 물때 곡선** 크게 + 지금 위치 표시, 다음 만조·간조 시각과 높이, "Rising/Falling" 화살표.
- 7일 표. 일출·일몰·달 모양(계산식으로 오프라인 산출).
- 즐겨찾기 관측소 몇 개. 마지막 데이터 캐시 → 바다 근처 신호 약할 때도 보이게("Last updated" 표시).

## 원칙
- 숫자는 NOAA 실제 예보값만. 데이터 못 받으면 솔직히 "No data" + 캐시 시각 표시. 가짜 곡선 금지.
- "Not for navigation" 표기 (항해용 아님).
- 광고: **배너만, 전면 광고 없음**(1등 앱 불만의 정반대가 우리 무기). 보상형은 부가 기능(예: 30일 표)에만 검토.
- 영어 UI, 피트(ft) 기본·미터 전환, 아이폰 전용·세로.

## 결정 필요 (개발 세션이 사용자에게 A/B 로)
- 앱 이름: 미국 검색어 조사 후 후보 2~3개.
- 번들 ID `com.soulfulfill.<이름>` — Apple 등록 전 확인.
- 광고 제거 단건 결제(예: $2.99)를 넣을지 — 1등 앱 리뷰 불만이 "단건 결제 없음"이었다. 지금까지 방침은 결제 없이 광고만.

  중간에 닫음 → 안 열림 안내, 영상 없음 → 최대 8초 "Loading…" 뒤 안내, 두 번 탭해도 영상 한 번, 신호 없음 → No data + Try again(가짜 표 없음).

- 남은 것: ASC 앱 레코드·AdMob 앱/광고 단위 2개(사용자) → 실제 ID 교체 → Release iOS(tides) → TestFlight → 스크린샷 → 심사.

### 2026-10-03 개발 세션 1
- NOAA 점검(작업 환경에서 NOAA 가 막혀 Actions `Fetch NOAA tides data` 로): 관측소 **3,499곳**(기준 R 1,256 / 보조 S 2,243), 목록 2MB·418ms,
  예보 65~300ms, **CORS `*`**(웹 미리보기에서도 폰이 NOAA 직접 호출). 보조 관측소는 6분 예보가 없다(hilo 만) → 곡선은 코사인 보간 + "estimated" 표기.
- 관측소 목록은 앱에 내장(`assets/stations.json` 225KB, 오프라인 검색·가장 가까운 관측소). NOAA 메타데이터의 서머타임(1,257곳 빈 값)·시간대(39곳 오류)는
  지역 규칙으로 보정(`tools/tides/make_asset.py`).
- 앱 `tides_app/flutter/`: 첫 화면(내 위치 / 검색) → 물때 화면 한 장(Rising/Falling·지금 높이·다음 만조/간조, 하루 곡선 탭·끌기로 시각 읽기,
  일출일몰 그늘·달 모양, 7일 표 누르면 그날 곡선) · 관측소 화면(즐겨찾기·근처·인기·검색) · 설정(ft/m, 데이터 설명, Not for navigation, 개인정보처리방침).
  예보는 기기에 저장(최대 12곳) → 신호 없으면 "Offline — saved …" 와 함께 저장본, 저장본도 없으면 "No data + Try again"(가짜 곡선 없음). 12시간마다 새로 받음.
- 일출일몰(NOAA 태양 계산식)·달 위상(Meeus) 오프라인 계산 — PyEphem 기준 일출일몰 ±90초, 달 위상 시각 ±3시간 테스트.
- 테스트 31개 통과(엔진 21: NOAA 현지시각표와 고/저조 일치·DST·캐시·검색 / 로봇 10: 모든 버튼·3기종·키보드·오프라인·자정·전 시간대 레이아웃).
  웹 클릭 점검 30/30 + 스크린샷 10장(`tides_app/qa/shots/`).
- 웹 미리보기 `docs/tides-app/`, 개인정보처리방침 `docs/tides-privacy.html`. iOS: 아이폰 전용·세로·위치 권한 문구. 광고는 배너 테스트 ID.
