# GPS 속도계 — 기획서 (기획 파트너, 2026-10-02)

## 왜
- Speedometer Simple 약 12.9만, Speedometer 55 약 6.5만 평가 → 수요 확인 (`plans/utility-research.md`).
- 1등의 불만: 거슬리는 광고 + **무료 체험이 연 $20 구독으로 넘어가는 함정**.
- 휴대폰 GPS 만 씀 → 오프라인, 서버·콘텐츠 없음, **전 세계 어디서나 동작**(선교지 포함). 제작 난이도 가장 낮음.

## 핵심 화면
- **아주 큰 숫자 속도** (mph 기본, km/h 전환) + 아날로그 게이지 선택.
- **HUD 모드**: 화면 좌우 반전 → 밤에 앞유리에 비춰 보기.
- **속도 경고**: 사용자가 정한 속도 넘으면 화면 빨갛게 + 소리. (도로 제한속도 데이터는 넣지 않는다 — 데이터 없음, 틀리면 위험)
- 이번 이동 기록: 최고·평균 속도, 거리, 시간. 자전거·달리기·보트 모드(단위·표시만 다름).
- GPS 신호 약하면 솔직히 "Weak GPS" 표시 (가짜 숫자 금지).

## 원칙
- 운전 중 조작 최소화: 시작하면 탭 없이 계속 보이게, 화면 꺼짐 방지.
- 광고: **배너만, 주행 중 전면 광고 절대 금지**(안전 + 1등 앱 불만의 정반대). 구독·체험 함정 없음.
- "Do not interact while driving" 안내 1회.
- 위치 권한 문구 정직하게, 위치 기록은 기기 밖으로 보내지 않음.
- 영어 UI, 아이폰 전용. HUD 때문에 가로 모드는 2차 검토.

## 결정 필요 (개발 세션이 사용자에게 A/B 로)
- 앱 이름: 미국 검색어 조사 후 후보 2~3개 (Glance 시리즈와 어울리게).
- 번들 ID `com.soulfulfill.<이름>` — Apple 등록 전 확인.

## 진행 순서
①경쟁 앱 화면·리뷰 불만 확인 → ②테스트 로봇(GPS 값은 가짜 위치 주입으로) → ③Flutter 개발 → ④광고
→ ⑤`Release iOS`(앱 선택형)에 추가 → ⑥TestFlight(실제 주행 확인은 사용자 '느낌' 피드백) → ⑦스토어

  200 mph 넘는 값 버림, 10초 넘은 캐시 위치 버림, 5초 측정 없으면 '--'·"No GPS signal", 오차 25 m 넘으면 "Weak GPS"(숫자 흐리게),

  설정, 첫 실행 안전 안내 1회, 권한 거절·위치 서비스 꺼짐·정확한 위치 꺼짐 안내(막힌 길 없음). **이동 기록은 모드마다 따로**(점검에서 찾은 버그).
