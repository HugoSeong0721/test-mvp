# 한붓 경로 퍼즐 (LinkedIn "Zip" 류) — 기획서 (기획 파트너, 2026-10-03)

## 왜 (`plans/research-8-fields.md`)
- LinkedIn 게임 하루 약 350만 명(2026-05, 1월 약 200만에서 증가). Queens·Tango 다음으로 Zip 이 인기.
- 같은 계열 Flow Free 4.8★ 약 40.5만 평가 → 장르 검증됨. Zip 따라한 앱들은 평가 약 90~100개 → **아직 강자 없음**.
- 코드가 판을 만든다(사람 콘텐츠 없음). 우리 Kitty Queens(캣도쿠)의 날짜 시드·하트·보상형 광고 구조를 재사용.

## 게임
- N×N 격자(5×5 → 8×8). **손가락으로 한 줄을 그어 모든 칸을 한 번씩 지나며, 숫자 1→2→3… 순서대로** 통과.
- 규칙 2개뿐(모든 칸 / 숫자 순서) — CLAUDE.md "규칙 2개까지, 화면에 보이게". 다음에 가야 할 숫자를 강조 표시.
- 조작은 **드래그로 따라 그리기** + 되돌아가면 지워짐(탭 순환 없음). 모바일 터치로 반드시 테스트.
- 생성: 모든 칸을 지나는 랜덤 경로 → 숫자 배치 → 백트래킹 풀이기로 **해 유일성 확인**.
- **오늘의 퍼즐**(기기 현지 날짜 시드, 연속 기록) + **무한 단계 모드**.
- 실패 없음(경로 퍼즐은 지우고 다시 그리면 됨) → 점수는 시간. 막히면 보상형 광고로 힌트(다음 몇 칸 공개).
