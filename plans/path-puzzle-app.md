# 한붓 경로 퍼즐 (LinkedIn "Zip" 류) — 기획서 (기획 파트너, 2026-10-03)

## 왜 (`plans/research-8-fields.md`)
- LinkedIn 게임 하루 약 350만 명(2026-05, 1월 약 200만에서 증가). Queens·Tango 다음으로 Zip 이 인기.
- 같은 계열 Flow Free 4.8★ 약 40.5만 평가 → 장르 검증됨. Zip 따라한 앱들은 평가 약 90~100개 → **아직 강자 없음**.
- 코드가 판을 만든다(사람 콘텐츠 없음). 우리 Kitty Queens(캣도쿠)의 날짜 시드·하트·보상형 광고 구조를 재사용.

## 게임
- N×N 격자(5×5 → 8×8). **손가락으로 한 줄을 그어 모든 칸을 한 번씩 지나며, 숫자 1→2→3… 순서대로** 통과.
- 규칙 2개뿐(모든 칸 / 숫자 순서) — CLAUDE.md "규칙 2개까지, 화면에 보이게". 다음에 가야 할 숫자를 강조 표시.
- 조작은 **드래그로 따라 그리기** + 되돌아가면 지워짐(탭 순환 없음). 모바일 터치로 반드시 테스트.
- 생성: 모든 칸을 지나는 랜덤 경로 → 숫자 배치 → 백트래킹 풀이기로 **해 유일성 확인**.
- **오늘의 퍼즐**(기기 현지 날짜 시드, 연속 기록) + **무한 단계 모드**.
- 실패 없음(경로 퍼즐은 지우고 다시 그리면 됨) → 점수는 시간. 막히면 보상형 광고로 힌트(다음 몇 칸 공개).

## 수익
- 배너 + 보상형(힌트). 단계 모드 몇 판마다 전면 광고는 TestFlight 느낌 보고 결정 (캣도쿠 세션 경험 참고).

### 2026-10-03 개발 세션 1
- ①조사(하위 작업자): 원조 게임은 6×6 기본·숫자 8~14개(평균 10)·**1에서 시작해 가장 큰 숫자에서 끝**·어려운 판엔 벽. 따라 만든 앱들 평가 수백 개 이하 —
  불만은 "힌트가 숫자만 강조하고 길은 안 보여 줌", "되돌리기 없음", "판 지우기에 코인", "2판마다 20초 광고", "115단계쯤 결제 유도". Flow Free(40.5만)도 광고·힌트 제한 불만.
  → 차별점: **되돌리기·지우기 무제한 무료, 힌트는 실제 길을 그어 줌, 강제 광고 없음(배너 + 원할 때 보는 힌트 영상), 단계 무제한 무료.**
  상표 주의: "Zip"(LinkedIn 출원)·Flow·Numbrix·Hidato 는 이름·키워드·설명 어디에도 안 씀.
- ②엔진 `lib/core/puzzle.dart`: backbite 로 무작위 한붓 경로 → 숫자 배치 → 다른 해가 처음 갈라지는 칸에 숫자 추가로 유일해 → 목표 개수까지 빼기.
  숫자 기본 개수 5×5:7, 6×6:9, 7×7:11, 8×8:13. 생성 8×8 평균 16ms(VM). xorshift32 + 노드 수 한도라 iOS·웹 같은 판(크롬에서 지문 테스트 통과).
- ③테스트: 엔진 8개(무식한 풀이와 해 개수 비교 포함), 규칙 12개, 로봇 15개(모든 버튼·드래그·빠른 휙 긋기·두 손가락·광고 지연/없음/중간 닫기/두 번 탭·3개 기기·큰 글씨 135%·잘린 글자·한글 노출), 웹 실제 터치 24개.
- ④앱: 오늘의 퍼즐 6×6(기기 현지 날짜, 연속 기록, 시간 이어 가기, 이미 풀면 연습) + 단계(1-3:5×5, 4-10:6×6, 11-25:7×7, 26+:8×8). 실패 없음 → 점수는 시간.
  조작: 줄 끝에서 끌기, 지난 칸으로 되돌아가면 지워짐, 줄 위 아무 칸을 누르면 거기까지 되돌림, 순서 아닌 숫자는 막고 이유 표시, 마지막 숫자에 일찍 닿으면 "빈칸 N개" 경고.
- ⑤광고: 배너 + 보상형 힌트 1자리(정답과 다른 부분을 지우고 다음 숫자까지, 최소 3칸). **지금은 Google 테스트 ID.**
