## 한국어 (ko-KR)

### 앱 이름 (30자 이내)

```
불길 탈출
```

검색 노출을 조금 더 노리려면 아래를 쓴다. 이름에 키워드를 넣으면 검색에 걸리지만
너무 길면 아이콘 아래에서 잘린다.

```
불길 탈출 - 한 손 점프 게임
```

### 간단한 설명 (80자 이내)

```
불길이 멈추지 않고 올라옵니다. 발판을 밟고 계속 위로 도망치세요.
```

### 자세한 설명 (4000자 이내)

```
멈추면 타 죽습니다.

아래에서 불길이 쉬지 않고 올라옵니다. 발판을 밟고 위로, 계속 위로 도망치세요.
잠깐 머뭇거리는 순간 불길이 발밑까지 닿습니다.

■ 한 손으로 됩니다
화면 왼쪽이나 오른쪽을 누르고 있기만 하면 됩니다.
점프는 자동, 양옆 벽은 통과합니다. 배울 게 없습니다.

■ 한 판은 짧습니다
30초에서 1분. 지하철에서, 엘리베이터 기다리며, 자기 전에.
죽으면 바로 다시 시작할 수 있습니다.

■ 쉬어가는 구간이 없습니다
불길은 느려지지 않습니다. 올라갈수록 발판은 멀어집니다.
방심할 틈을 주지 않는 것이 이 게임의 전부입니다.

■ 기록 경쟁
최고 고도가 남습니다. 랭킹판에서 자기 기록을 확인하고,
기록을 공유해 친구에게 같은 조건으로 도전장을 보낼 수 있습니다.

■ 도전 모드
도전 코드를 입력하면 같은 지형에서 시작합니다.
운이 아니라 실력으로 겨루고 싶을 때 쓰세요.

■ 가볍습니다
인터넷 연결 없이 동작합니다. 계정도 로그인도 필요 없습니다.
개인정보를 수집하지 않습니다.

지금 도망치세요.
```

## English (en-US)

### App name (30 chars)

```
Climb or Burn
```

`Fire Escape`는 동명 앱이 많아 피했다. `Climb or Burn`은 게임 안 부제와도 맞는다.

### Short description (80 chars)

```
The fire never stops rising. Hit the ledges and keep climbing, or burn.
```

### Full description (4000 chars)

```
Stop moving and you burn.

Fire rises from below and it never slows down. Hit the ledges, climb higher,
and keep climbing. Hesitate for a second and the flames reach your feet.

■ One thumb, no tutorial
Hold the left or right side of the screen. That is the whole control scheme.
Jumping is automatic. You pass through the side walls. Nothing to learn.

■ Runs are short
Thirty seconds to a minute. On the train, waiting for an elevator, before bed.
Die and you are back in instantly.

■ No safe moments

Enter a challenge code to start on identical terrain.
For when you want the result decided by skill instead of luck.

Now run.
```

## 등록 시 주의

**게임 화면이 전부 한국어입니다.** 영어 등록정보만 올리면 영어권 사용자가
받았을 때 한국어 UI를 보게 되어 별점이 깎입니다. 둘 중 하나를 택해야 합니다.

1. **한국어를 기본 언어로 등록**하고 배포 국가를 한국 + 한인 인구가 많은 국가 중심으로
2. 게임 UI에 영어를 추가한 뒤 영어 등록정보를 올리기

같은 이유로, 해외 테스터 교환 커뮤니티에서 12명을 모으면 그들도 한국어 화면을 보게 된다.
테스터를 어디서 구하느냐가 이 결정과 묶여 있다.

## 콘텐츠 등급 설문 참고

- 폭력 표현 없음 · 성적 콘텐츠 없음 · 언어 표현 없음 · 도박 요소 없음
- 사용자 간 소통 기능 없음 (랭킹은 기기 안에만 저장)
- 개인정보 수집 없음 (광고 SDK 추가 시에는 광고 ID 수집으로 답해야 함)
- 대상 연령 **13세 이상** — `docs/privacy.html`이 13세 미만 비대상으로 작성되어 있으므로
  콘솔에서도 동일하게 맞출 것
