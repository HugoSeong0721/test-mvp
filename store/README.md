# 스토어 등록 자료

Google Play 등록에 쓸 이미지와 문구를 모아두는 곳. `docs/`가 아니므로 Pages로 배포되지 않는다.

## 불길 탈출 (`firechase/`)

실제로 플레이해서 캡처한 것. 헤드리스 Chromium, 뷰포트 432×864 × 배율 2.5.

| 파일 | 장면 | 크기 |
|---|---|---|
| `01-start.png` | 시작 화면 (제목·규칙·시작 버튼) | 1080×2160 |
| `02-climb.png` | 등반 중 (불길·발판·캐릭터) | 1080×2160 |
| `03-higher.png` | 고지대 | 1080×2160 |
| `04-gameover.png` | 게임오버 | 1080×2160 |

## Play 스토어 규격

| 항목 | 요구사항 | 상태 |
|---|---|---|
| 폰 스크린샷 | 최소 2장, 최대 8장. 320~3840px, 9:16 또는 16:9 | **완료** (4장) |
| 앱 아이콘 | 512×512 PNG, 32비트 알파 | 미작성 |
| 그래픽 이미지 | 1024×500 PNG/JPG, 알파 없음 | 미작성 |
| 앱 이름 | 30자 이내 | 미작성 |
| 간단한 설명 | 80자 이내 | 미작성 |
| 자세한 설명 | 4000자 이내 | 미작성 |
| 개인정보처리방침 URL | 공개 접근 가능 | **완료** — `docs/privacy.html` |

## 남은 작업

- 아이콘·그래픽 이미지 제작
- 스토어 문구 작성
- 게임을 안드로이드 앱으로 변환 (이 저장소는 단일 HTML 파일)

## 재캡처 방법

게임 화면이 바뀌면 스크린샷도 다시 뽑아야 한다. 자동 조종이 발판을 잘 못 밟아
고도가 낮게 찍히므로, 높은 점수 장면이 필요하면 직접 플레이해서 캡처하는 편이 빠르다.
